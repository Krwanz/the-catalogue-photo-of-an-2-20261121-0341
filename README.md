A catalogue photograph of an impossible gadget: PORTA-DOOR, a folding door
to anywhere. A single modern white folding door stands in a clean studio;
through its open doorway is a tropical beach in Bali, while the studio
around it stays plain white. A folded copy leans in its box beside it, and
the make.fun ghost — tourist hat, sunglasses, suitcase — is about to walk
through.

Entry for the make.fun bounty: https://make.fun/bounty/the-catalogue-photo-of-an-2-20261121-0341

## How it works

`catalogue.png` is the finished 819×1024 catalogue photo (under 1 MiB).
`main.ts` copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`. Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
